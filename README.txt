FUTURE SHAPERS - CLEAN PROJECT
================================

HTML pages:
- mm.html       Myanmar: ကြိယာအစု
- science.html  Science: မျိုးပွားခြင်း (Reproduction)
- civ.html      Moral & Civics: ငြိမ်းချမ်းစွာအတူယှဉ်တွဲနေထိုင်ခြင်း

Shared files:
- css/style.css
- js/script.js
- assets/future-shapers-bg.jpg

Naming guide:
- IDs are used for unique page sections and JavaScript targets.
- Classes are used for reusable design elements.
- Class names describe their purpose, for example:
  .site-header, .subject-nav, .hero, .panel, .topic-card, .quiz-option.
- Subject page themes use:
  .page--mm, .page--science, .page--civ.

How to run:
Open any one of the three HTML files in a browser.
Use the navigation bar to move between subjects.

No Bootstrap, Flask, database, or build tools are used.
The background is based on the image supplied by the team.
